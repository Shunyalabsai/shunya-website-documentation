Realtime streaming over WebSocket

For live audio where partial results matter: voice agents, IVR, live captioning. Open a WebSocket, stream raw PCM frames, and receive partial and final transcripts as the speaker talks. For pre-recorded files use batch transcription instead — it's faster and returns the whole transcript at once.

Endpoint

Live speech-to-text over WebSocket (English + 22 Indic languages). Also reachable at WS /ws (same behaviour).

wss://asrv2prod.shunyalabs.ai/v1/realtime

Connection lifecycle

sequenceDiagram participant C as Client participant S as Shunya ASR C->>S: Open WebSocket C->>S: Init JSON (token, language, sample_rate, …) S-->>C: ready { echoes settings } loop Audio streaming C->>S: Raw PCM frames (16-bit LE mono) S-->>C: partial (provisional) end C->>S: "end" S-->>C: final (per segment, stable) S-->>C: error (only on rejection)

Authentication

The access token from POST /auth/token — the same token used for batch transcription. Send it one of three ways:

  • a field in the first message: {"token": "<access_token>", ...} (the field api_key is also accepted for the same value), or
  • a query parameter: ?token=<access_token>, or
  • an Authorization: Bearer <access_token> header on the WebSocket upgrade.

Step 1: Open the session

Send one JSON message (text or binary frame). The fields you set here apply for the whole connection and can't change mid-stream:

{ "token": "<access_token>", "language": "hi", "sample_rate": 8000, "diarize": true, "num_speakers": 2 }

Init fields

FieldRequiredNotes
tokenyes (or query param / Bearer header)The access token from /auth/token.
languageyesen, hi, bn, gu, kn, ml, mr, ta, te, … There is no auto-detect — omitting language or sending "auto" produces wrong output.
sample_ratenoOf the PCM you will send. Default 16000; 8000 supported.
diarizenotrue labels each final with a speaker.
num_speakersnoHow many speakers, if known — improves labelling.
Language is required
Unlike batch, streaming has no auto-detect. You must always set language to a supported code (e.g. hi, en). Omitting it or sending "auto" produces wrong output.

Step 2: Send audio

Send raw binary WebSocket frames: 16-bit signed PCM, little-endian, mono, at the sample_rate you declared, 20–320 ms per frame (20 ms = 320 bytes at 8 kHz is typical for telephony), no headers (raw PCM, not WAV/MP3). Pace at roughly realtime — a 20 ms frame every 20 ms.

Frame format
16-bit signed PCM · little-endian · mono · no WAV/MP3 headers · 20–320 ms per frame.

Step 3: Finish

Send the text message end.

Response events

{"type":"ready","language":"hi","sample_rate":8000,"diarize":true}
{"type":"partial","seg":3,"delta":"और फिर","text":"हाँ जी बोलिए और फिर","elapsed_ms":8420}
{"type":"final","seg":3,"text":"हाँ जी बोलिए और फिर वो अकाउंट","speaker":"SPEAKER_00","elapsed_ms":11200}
{"type":"error","error":"invalid or missing api key"}
TypeMeaning
readySession open, waiting for audio. Sent once, echoes your settings — check them before streaming.
partialIn-progress text for the current segment (~every 640 ms). delta = new since the last partial; text = segment so far. Provisional, may change.
finalSegment closed; its text won't change. seg increments per segment.
errorRequest rejected; the socket closes afterwards.
Building the transcript
Concatenate final.text in seg order; use partial for live display only. speaker appears on final when diarize was set (SPEAKER_00, …, stable for the connection); it may be null on a very short segment — treat as unknown, not an error.

Example

python
import asyncio, json, websockets

async def transcribe(pcm_frames, token, lang="hi", sr=8000):
    url = "wss://asrv2prod.shunyalabs.ai/v1/realtime"
    finals = []
    async with websockets.connect(url, max_size=None) as ws:
        await ws.send(json.dumps({"token": token, "language": lang, "sample_rate": sr}))

        async def read():
            async for msg in ws:
                ev = json.loads(msg)
                if ev.get("type") == "final" and ev.get("text"):
                    finals.append(ev["text"])
                elif ev.get("type") == "error":
                    raise RuntimeError(ev["error"])

        reader = asyncio.create_task(read())
        for frame in pcm_frames:                 # bytes: int16 LE mono
            await ws.send(frame)
            await asyncio.sleep(0.02)             # pace ~realtime
        await ws.send("end")
        await reader
    return " ".join(finals)
node
import WebSocket from "ws";

const ws = new WebSocket("wss://asrv2prod.shunyalabs.ai/v1/realtime");

ws.on("open", () => {
  ws.send(JSON.stringify({
    token: process.env.ACCESS_TOKEN,   // from POST /auth/token
    language: "hi",                    // required — no auto-detect
    sample_rate: 8000,
  }));
});

const finals = [];
ws.on("message", (raw) => {
  const ev = JSON.parse(raw.toString());
  if (ev.type === "ready") console.log("Session ready:", ev);
  else if (ev.type === "partial") console.log("partial:", ev.text);
  else if (ev.type === "final" && ev.text) finals.push(ev.text);
  else if (ev.type === "error") console.error("Error:", ev.error);
});

// Stream raw 16-bit PCM mono frames from a source (mic, telephony media, file)
audioSource.on("data", (chunk) => ws.send(chunk));
audioSource.on("end",  () => ws.send("end"));
Pacing & reconnection
Pace audio at realtime — pushing a long recording as fast as the socket allows can outrun the decoder and end the connection early. On an unexpected close, reconnect and resume; transcript already received via final events stays valid.
