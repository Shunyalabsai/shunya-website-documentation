Speech-to-Text (ASR)

Zero STT is Shunya's speech recognition family. One API surface for batch and streaming, a choice of four models tuned for different domains, diarization and word timestamps on the transcript, and a Speech Intelligence endpoint that adds intent, summary, and sentiment analysis over the text.

Batch vs Streaming

Same models, same authentication, different transports. Pick batch when you have a complete audio file in hand. Pick streaming when audio is arriving live and you want partial transcripts as the speaker is still talking.

Batch
HTTP POST, transcribe an audio file

Accepts multipart/form-data. Send one of file, audio_base64, or url (max 50 MB); everything else is optional.

Models available
  • zero-indic, Native handling of Hindi, Tamil, Telugu, Kannada, Marathi, Bengali, and more
  • zero-universal, Strongest on English and international content
  • zero-med, Medical/clinical audio, auto-applies medical terminology correction
  • zero-codeswitch, Code-switched speech (Hinglish, Tanglish, etc.), restores English words to Latin script

Streaming
WebSocket, real-time partials + finals

Real-time speech-to-text over WebSocket (English + 22 Indic languages). Send raw binary PCM frames and receive partial + final results as the speaker talks.

Audio format
  • 16-bit signed PCM, little-endian, mono
  • At your declared sample_rate: 16000 default, 8000 supported
  • 20–320 ms per frame, paced at roughly realtime
  • No headers: raw PCM, not WAV/MP3

Pick a model

Every request takes a model field. There are four to choose from:

zero-indic

Native handling of Hindi, Tamil, Telugu, Kannada, Marathi, Bengali, and more. The default for Indian-language content.

View model →
zero-universal

Strongest on English and international content. Use when the input could be anything; set language_code=auto.

View model →
zero-med

Clinical / medical speech with drug, procedure, and diagnosis vocabulary. Auto-applies medical terminology correction.

View model →
zero-codeswitch

Native handling of mixed Hindi-English (Hinglish), Tamil-English (Tanglish) and similar blends. Restores English words to Latin script.

View model →

Your first request

Minimum viable: mint a token, then transcribe a file.

# 1. Exchange your API key for a short-lived access token
curl --location --request POST 'https://asrv2prod.shunyalabs.ai/auth/token' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <API_KEY>'

# 2. Transcribe with the access token
curl --location 'https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --form 'file=@"meeting.wav"' \
  --form 'model=zero-indic'

Or pass a URL instead of uploading a file:

curl --location 'https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --form 'url=https://example.com/call.wav' \
  --form 'model=zero-indic'
Token lifetime
The access token lasts ~15 minutes. Cache and reuse it for both batch and streaming; re-mint at /auth/token on expiry or a 401. Authentication →
