ASR features

What you can do on top of a transcript: per-speaker diarization, word timestamps, named speaker enrolment, and Speech Intelligence (NLP analysis over the text via the separate POST /v1/speechintelligence endpoint.

Auth reminder
Every request below authenticates with the access token from POST /auth/token as Authorization: Bearer <ACCESS_TOKEN>. Authentication →

1. Diarization

"Who spoke when." Set diarize=true on batch transcription or on the realtime stream to label every segment with a speaker. Provide num_speakers as a hint to improve the labelling when you know the count.

Batch request:

curl --location 'https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --form 'file=@"meeting.wav"' \
  --form 'language_code=hi' \
  --form 'diarize=true' \
  --form 'num_speakers=2' \
  --form 'response_format=verbose_json'

Response:

{
  "text": "the transcribed text",
  "segments": [ { "start": 0.0, "end": 2.4, "text": "…", "speaker": "SPEAKER_00" } ],
  "speakers": [ "SPEAKER_00", "SPEAKER_01" ],
  "speaker_turns": [ { "start": 0.0, "end": 2.4, "speaker": "SPEAKER_00" } ]
}
  • Speaker labels are stable per request/connection: SPEAKER_00, SPEAKER_01, …
  • In streaming, speaker appears on each final event when diarize is set, and may be null on a very short segment (treat as unknown, not an error).
  • Realtime init: {"token": "…", "language": "hi", "diarize": true, "num_speakers": 2}. Streaming guide →

2. Word timestamps

Word-level timing is included in the verbose_json response of batch transcription via the words array; no extra flag needed.

Request:

curl --location 'https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --form 'file=@"call.wav"' \
  --form 'language_code=hi' \
  --form 'response_format=verbose_json'

Response:

{
  "words": [ { "word": "…", "start": 0.0, "end": 0.3 } ]
}

3. Speech Intelligence: POST /v1/speechintelligence

NLP analysis (intent, summary, sentiment, key terms, …) over text. Send the transcript (or any text) as JSON and get the analysis back. Request fields are enable_intent_detection, enable_summarization, and enable_sentiment_analysis; all optional, combine freely.

Request:

curl --location 'https://asrv2prod.shunyalabs.ai/v1/speechintelligence' \
  --header 'accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --data-raw '{
    "text": "…",
    "enable_intent_detection": true,
    "enable_summarization": true,
    "enable_sentiment_analysis": true
  }'

Response:

{
  "success": true,
  "text": "…",
  "analysis": {
    "intent": "…",
    "summary": "…",
    "sentiment": "…"
  }
}
  • Intent detection: enable_intent_detection: true → analysis.intent.
  • Summarization: enable_summarization: true → analysis.summary.
  • Sentiment analysis: enable_sentiment_analysis: true → analysis.sentiment.
  • Errors: 400 (text required), 401/403 (auth), 503 (analysis unavailable).

4. Speaker enrolment

Enrol a named voiceprint so it is recognised in later calls.

Register a speaker: POST /v1/speakers/register

Send name and an audio file (multipart/form-data). project is optional and scopes the speaker library.

curl --location 'https://asrv2prod.shunyalabs.ai/v1/speakers/register' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --form 'name=Priya' \
  --form 'file=@"priya_sample.wav"' \
  --form 'project=support_team'

Response:

{ "success": true, "speaker": "Priya", "message": "…" }

Delete a speaker: DELETE /v1/speakers/delete

Remove a named voiceprint. Send name (and optionally project) as form fields.

curl --location --request DELETE 'https://asrv2prod.shunyalabs.ai/v1/speakers/delete' \
  --header 'accept: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --form 'name=Priya' \
  --form 'project=support_team'

Response:

{ "success": true }
