Speech Intelligence

NLP analysis over text: intent, summary, sentiment, key terms, and more, via the POST /v1/speechintelligence endpoint. Feed it a transcript (or any text) and get the analysis back in one JSON response.

Endpoint & auth
POST https://asrv2prod.shunyalabs.ai/v1/speechintelligence · application/json · authenticated with the access token from POST /auth/token as Authorization: Bearer <ACCESS_TOKEN>. Errors: 400 (text required), 401/403 (auth), 503 (analysis unavailable).

How to call it

Send the text to analyse plus the enable_* flags for the capabilities you want. All flags are optional and combine freely. The result lives in the analysis object of the response.

  1. Get a transcript from batch transcription or realtime streaming.
  2. POST the text to /v1/speechintelligence with the flags you need.
  3. Read analysis.intent, analysis.summary, and analysis.sentiment on the response.

All features

01

Intent detection

enable_intent_detection=true

Classifies the overall intent of the text.

Show request & response

Request

curl --location 'https://asrv2prod.shunyalabs.ai/v1/speechintelligence' \
  --header 'accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --data-raw '{
    "text": "…",
    "enable_intent_detection": true
  }'

Response

{
  "success": true,
  "text": "…",
  "analysis": {
    "intent": "…"
  }
}

Combine features

Enable everything you need in one request:

curl --location 'https://asrv2prod.shunyalabs.ai/v1/speechintelligence' \
  --header 'accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer <ACCESS_TOKEN>' \
  --data-raw '{
    "text": "…",
    "enable_intent_detection": true,
    "enable_summarization": true,
    "enable_sentiment_analysis": true
  }'

Returns all three analyses together:

{
  "success": true,
  "text": "…",
  "analysis": {
    "intent": "…",
    "summary": "…",
    "sentiment": "…"
  }
}
