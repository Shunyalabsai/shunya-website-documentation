TTS quickstart

Sign up, generate an API key, exchange it for a Bearer token, then synthesize. By the end of this page you'll have a speech.wav on disk and know how to use the education LaTeX and OpenAI-compatible endpoints too.

1. Sign up and generate an API key

Visit shunyalabs.ai and sign up or log in. Complete the onboarding flow; testing credits are added to your account. Generate an API key from your ShunyaLabs account.

Security
Keep API keys and authentication tokens on the server side. Do not expose them in browser code, mobile app bundles, public repositories, or logs.

2. Exchange the API key for a Bearer token

ShunyaLabs TTS APIs use a short-lived Bearer token. Exchange your API key for a token at the authentication endpoint. expires_in specifies the requested token lifetime in seconds (86,400 in the example is 24 hours).

curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'

Use the returned token as Authorization: Bearer YOUR_TOKEN on every TTS request. Store the API key securely in your backend or secret manager, reuse the token until it approaches expiry, then obtain a fresh token. Never send your API key directly to end-user clients.

3. Standard TTS

Call the Omni Voice synthesis endpoint with text and voice.

shell
curl -X POST 'https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "text": "If Modi is prime minister who is Amit Shah?",
    "voice": "Meera"
  }' \
  --output speech.wav
python
import requests

resp = requests.post(
    "https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={
        "text": "If Modi is prime minister who is Amit Shah?",
        "voice": "Meera",
    },
)
resp.raise_for_status()
with open("speech.wav", "wb") as f:
    f.write(resp.content)

4. Education TTS with LaTeX

For educational content containing mathematical expressions, enable LaTeX processing and provide the content language on the same Omni Voice endpoint.

curl -X POST 'https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "text": "If $x^2 = 49$, what is the value of x?",
    "voice": "Meera",
    "latex": true,
    "language": "en"
  }' \
  --output math.wav

Set latex to true when the input contains LaTeX expressions, and use language to identify the content language.

5. Voice Agent / OpenAI-compatible

For real-time voice-agent frameworks expecting an OpenAI-compatible speech interface, use the /v1/audio/speech endpoint. Raw PCM output is useful for streaming and voice-agent pipelines; select the response format required by your integration as supported by the API.

curl -X POST 'https://ttsv2.shunyalabs.ai/v1/audio/speech' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "tts-1",
    "input": "Hello, how are you today?",
    "voice": "Meera",
    "response_format": "pcm"
  }' \
  --output speech.pcm

Pipecat

from pipecat.services.openai import OpenAITTSService

tts = OpenAITTSService(
    api_key="YOUR_TOKEN",
    base_url="https://ttsv2.shunyalabs.ai/v1",
    voice="nova",
)
Pipecat note
The api_key field name comes from Pipecat's OpenAI-compatible service interface; pass the ShunyaLabs auth token as its value. For Pipecat, use an OpenAI-compatible voice name such as nova in the client configuration.
