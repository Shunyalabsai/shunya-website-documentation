LLM → TTS streaming pipeline

The core latency pattern for voice agents. Pipe LLM output into ShunyaLabs TTS as sentences complete, instead of waiting for the full response, so audio starts sooner and memory stays constant.

Why it matters

A full-text pipeline buffers the entire LLM response, then synthesizes it as one blob. A sentence-buffered pipeline sends each complete sentence to TTS as soon as the LLM finishes it, so the first audio reaches the speaker while the LLM is still generating the rest. The trade-off is a little more code: you accumulate tokens, detect sentence boundaries, and flush each sentence in turn.

The pattern

sequenceDiagram participant U as User participant A as Your app participant L as LLM participant T as Shunya TTS participant S as Speaker U->>A: speaks A->>L: user message (streaming) loop per token L-->>A: token A->>A: buffer += token alt sentence ended AND len(buffer) > 15 A->>T: synthesize sentence T-->>S: audio A->>A: buffer = "" end end L-->>A: [stream done] A->>T: synthesize remaining buffer T-->>S: audio

Sentence-buffering strategy

Flush to TTS at sentence boundaries, not word boundaries. Word-by-word flushes hurt prosody; the model needs full sentences to produce natural intonation.

  • Accumulate incoming tokens into a string buffer.
  • Flush when a sentence-ending punctuation mark appears: . ! ? ;
  • Apply a minimum buffer length (e.g. 15 characters) to avoid flushing fragments like "Yes."
  • After the LLM stream ends, always flush the remaining buffer; LLMs often end mid-sentence.

LLM → ShunyLabs pipeline

Pick your LLM provider; the pattern is the same on both sides: stream tokens out of the LLM, buffer them until a sentence boundary, then flush each complete sentence into Shunya TTS through the OpenAI-compatible endpoint (POST /v1/audio/speech, raw PCM for playback).

python
from openai import AsyncOpenAI

llm = AsyncOpenAI()  # your LLM provider
tts = AsyncOpenAI(api_key=TOKEN, base_url="https://ttsv2.shunyalabs.ai/v1")

async def speak(sentence: str):
    resp = await tts.audio.speech.create(
        model="tts-1",
        input=sentence,
        voice="Meera",
        response_format="pcm",
    )
    for frame in pcm_frames(resp.content):
        speaker.write(frame)

async def gpt_to_tts(user_message: str):
    buffer = ""
    stream = await llm.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": user_message}],
        stream=True,
    )
    async for chunk in stream:
        token = chunk.choices[0].delta.content or ""
        buffer += token
        if token in (".", "!", "?", ";") and len(buffer) > 15:
            await speak(buffer)
            buffer = ""

    # Flush remaining buffer after LLM stream ends
    if buffer.strip():
        await speak(buffer)

def pcm_frames(data, frame_bytes=320):
    """Split PCM bytes into frames (320 bytes = 20 ms at 16 kHz)."""
    return (data[i : i + frame_bytes] for i in range(0, len(data), frame_bytes))

Interruption handling

In voice agents, users often talk over the bot. When your ASR emits a partial or final event from the user while the bot is speaking, cancel the in-flight TTS playback so the user gets the floor immediately.

import asyncio
from openai import AsyncOpenAI

tts = AsyncOpenAI(api_key=TOKEN, base_url="https://ttsv2.shunyalabs.ai/v1")

class VoiceAgent:
    def __init__(self):
        self.tts_task = None
        self.interrupted = asyncio.Event()

    async def on_user_speech_detected(self):
        """Called by ASR when the user starts speaking."""
        self.interrupted.set()
        if self.tts_task:
            self.tts_task.cancel()

    async def speak(self, text: str):
        self.interrupted.clear()

        async def _speak():
            resp = await tts.audio.speech.create(
                model="tts-1", input=text, voice="Meera", response_format="pcm",
            )
            for frame in pcm_frames(resp.content):
                if self.interrupted.is_set():
                    break
                speaker.write(frame)

        self.tts_task = asyncio.create_task(_speak())
        await self.tts_task

Best practices

Minimising time to first audio

  • Use PCM output (response_format="pcm"), no client-side decoding.
  • Shorter sentences = faster response. Consider instructing your LLM to be concise in conversational contexts.
  • Synthesize sentence by sentence as the LLM stream completes each one, rather than waiting for the full response.

Handling LLM response edge cases

  • LLM ends mid-sentence. Always flush the remaining buffer after the LLM stream ends.
  • Markdown tokens in voice output. Strip **, ##, *, etc. before sending to TTS.
  • Empty strings. Check buffer.strip() before synthesizing, avoid empty calls.
  • Function calls. Don't send tool-call tokens to TTS. Filter to content-only tokens.

Graceful degradation

  • If TTS fails mid-stream, fall back to a pre-recorded "sorry, let me try again" clip.
  • If the LLM is slow, send a pre-recorded filler like "Let me check that for you..." so the user hears something quickly.

Full voice agent skeleton

import asyncio, json, websockets
from openai import AsyncOpenAI

llm = AsyncOpenAI()  # your LLM provider
tts = AsyncOpenAI(api_key=TOKEN, base_url="https://ttsv2.shunyalabs.ai/v1")

class VoiceAgent:
    def __init__(self):
        self.speaking = False
        self.interrupt = asyncio.Event()

    async def listen_loop(self):
        async with websockets.connect("wss://asrv2prod.shunyalabs.ai/v1/realtime") as asr:
            await asr.send(json.dumps({
                "token": ACCESS_TOKEN, "language": "hi", "sample_rate": 16000,
            }))
            # stream raw 16-bit PCM frames here, then send "end"
            async for raw in asr:
                msg = json.loads(raw)
                if msg["type"] == "final" and self.speaking:
                    self.interrupt.set()        # user cut in
                elif msg["type"] == "final":
                    await self.respond(msg["text"])

    async def respond(self, user_text):
        self.speaking = True
        self.interrupt.clear()
        buffer = ""
        stream = await llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": user_text}],
            stream=True,
        )
        async for chunk in stream:
            if self.interrupt.is_set():
                break
            token = chunk.choices[0].delta.content or ""
            buffer += token
            if token in (".", "!", "?", ";") and len(buffer) > 15:
                await self.speak(buffer)
                buffer = ""
        if buffer.strip() and not self.interrupt.is_set():
            await self.speak(buffer)
        self.speaking = False

    async def speak(self, text: str):
        resp = await tts.audio.speech.create(
            model="tts-1", input=text, voice="Meera", response_format="pcm",
        )
        for frame in pcm_frames(resp.content):
            if self.interrupt.is_set():
                break
            speaker.write(frame)
