Contact centres

Contact centres is one of the verticals Shunya Labs targets, described on the company site as "Real-time analytics and agent assistance with conversational insights." This page links the Shunya capabilities you'll typically reach for when building in this space.

Recommended Shunya capabilities

CapabilityShunya componentSource
Live streaming ASR WebSocket endpoint wss://asrv2prod.shunyalabs.ai/v1/realtime with ready, partial, final, and error events ASR API guide
Telephony codecs 8 kHz PCM streaming (sample_rate: 8000 in the init message); send raw 16-bit PCM frames ASR API guide
Code-switched audio zero-codeswitch for Hinglish / Tanglish; zero-indic for general Indian-language audio ASR API guide
Speaker separation diarize=true on batch (or in the streaming init message), plus num_speakers as an optional hint ASR API guide
Per-call analytics Run the transcript through POST /v1/speechintelligence with enable_intent_detection, enable_sentiment_analysis, and enable_summarization ASR API guide
Data privacy Raw audio is deleted on completion and transcripts are delivered over TLS; see the Security & Compliance page Security policy
Bot voice / IVR prompts Zero TTS via the OpenAI-compatible endpoint with response_format="pcm", raw PCM useful for streaming and voice-agent pipelines TTS API Integration Guide

Source: Shunya Labs website (Contact Centers vertical), Shunya Labs ASR Gateway API Reference, ShunyaLabs TTS API Integration Guide. Named CCaaS integration patterns (Genesys, NICE, Five9, Avaya) are not officially documented by Shunya, for example architectures see the Hands-on evaluation page, where they are clearly marked as illustrative.
