Pipecat integration

Add Shunya TTS to a Pipecat voice agent with the OpenAI-compatible TTS service. Configure OpenAITTSService with the Shunya endpoint as base_url and your Shunya Bearer token as api_key, no glue code required.

1. Mint a Bearer token

Exchange your API key for a short-lived Bearer token at POST https://app.shunyalabs.ai/api/auth/token, then pass the token to the service. Keep the API key on the server side; never send it to end-user clients.

curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'

2. Configure the TTS service

api_key is Pipecat's field name. Pass the ShunyaLabs auth token as its value, and point base_url at the Shunya compatible endpoint. For Pipecat, use an OpenAI-compatible voice name such as nova.

from pipecat.services.openai import OpenAITTSService

tts = OpenAITTSService(
    api_key="YOUR_TOKEN",
    base_url="https://ttsv2.shunyalabs.ai/v1",
    voice="nova",
)

3. Wire it into a pipeline

Drop the service into any Pipecat pipeline in place of the TTS node:

from pipecat.pipeline.pipeline import Pipeline
from pipecat.pipeline.runner import PipelineRunner
from pipecat.pipeline.task import PipelineParams, PipelineTask
from pipecat.services.openai import OpenAILLMService, OpenAITTSService
from pipecat.transports.services.daily import DailyParams, DailyTransport

tts = OpenAITTSService(
    api_key="YOUR_TOKEN",
    base_url="https://ttsv2.shunyalabs.ai/v1",
    voice="nova",
)

pipeline = Pipeline([
    transport.input(),
    stt,
    llm,
    tts,
    transport.output(),
])
task = PipelineTask(pipeline, PipelineParams(allow_interruptions=True))
await PipelineRunner().run(task)
Response format
The OpenAI-compatible endpoint returns audio as supported by the API. Raw PCM output is useful for streaming and voice-agent pipelines. See the OpenAI-compatible endpoint in the TTS API reference.
Keep credentials on the server side
Do not expose API keys or auth tokens in browser code, mobile app bundles, public repositories, or logs.

Source: ShunyaLabs TTS API Integration Guide, §4 Voice Agent / OpenAI-Compatible TTS.
