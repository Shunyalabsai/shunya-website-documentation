Python integration

Integrate ShunyaLabs TTS from Python without a custom SDK. Mint a short-lived Bearer token, then call the omni-voice endpoint with requests, or point the OpenAI Python SDK at the compatible endpoint.

1. Mint a Bearer token

Exchange your API key for a short-lived Bearer token at POST https://app.shunyalabs.ai/api/auth/token. Keep the API key on the server side; never send it to end-user clients.

python
import os, requests

token = requests.post(
    "https://app.shunyalabs.ai/api/auth/token",
    headers={"api-key": os.environ["SHUNYALABS_API_KEY"]},
    json={"expires_in": 86400},  # lifetime in seconds, example 24 h
).json()["token"]
shell
curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'
Keep credentials on the server side
Do not expose API keys or auth tokens in browser code, mobile app bundles, public repositories, or logs.

2. Standard TTS

Send the token as Authorization: Bearer YOUR_TOKEN and call POST https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize.

r = requests.post(
    "https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize",
    headers={"Authorization": f"Bearer {token}"},
    json={"text": "Hello, how are you today?", "voice": "Meera"},
    timeout=120,
)
r.raise_for_status()
with open("hello.wav", "wb") as f:
    f.write(r.content)

3. Education TTS (LaTeX)

Add "latex": true when the input contains LaTeX expressions, and "language" to identify the content language:

r = requests.post(
    "https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize",
    headers={"Authorization": f"Bearer {token}"},
    json={"text": "If $x^2 = 49$, what is the value of x?", "voice": "Meera", "latex": true, "language": "en"},
    timeout=120,
)

4. OpenAI-compatible endpoint

For voice-agent and Pipecat pipelines, point the official OpenAI Python SDK at the ShunyaLabs compatible endpoint POST https://ttsv2.shunyalabs.ai/v1/audio/speech. Raw PCM output (response_format="pcm") is useful for streaming and voice-agent pipelines.

from openai import OpenAI

client = OpenAI(api_key=token, base_url="https://ttsv2.shunyalabs.ai/v1")

resp = client.audio.speech.create(
    model="tts-1",
    input="Hello, how are you today?",
    voice="Meera",
    response_format="pcm",
)
resp.stream_to_file("hello.pcm")

Select the response format required by your integration as supported by the API. See TTS API reference for the full flow and the Pipecat example.

5. Security best practices

  • Store the API key in a backend or secrets manager, not in source code.
  • Mint the Bearer token from the backend and reuse it until near expiry, then refresh.
  • Never send the API key to end-user clients.
  • Add .env to .gitignore to prevent accidental commits.
