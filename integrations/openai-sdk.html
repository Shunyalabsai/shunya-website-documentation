OpenAI SDK (compatible)

ShunyaLabs' voice-agent TTS endpoint is OpenAI-compatible. You can use the official OpenAI Python SDK by pointing base_url to the ShunyaLabs endpoint and passing your Bearer token, no other client changes needed.

Why this is useful

  • You're already using openai.audio.speech.create() and you want to switch to ShunyaLabs without rewriting your call sites.
  • You want to A/B test voices across providers from one client interface.
  • Your team standardised on the OpenAI SDK and prefers not to maintain a second SDK.

Authenticate first

Generate an API key from your ShunyaLabs account, then exchange it for a short-lived Bearer token at POST /api/auth/token. Pass the token as api_key; the SDK sets the Authorization header for you. Keep the API key on the server side; never send it to end-user clients.

curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'

Drop-in code sample

from openai import OpenAI

client = OpenAI(
    api_key="YOUR_TOKEN",
    base_url="https://ttsv2.shunyalabs.ai/v1",
)

response = client.audio.speech.create(
    model="tts-1",
    input="Hello, how are you today?",
    voice="Meera",
    response_format="pcm",
)

response.stream_to_file("output.pcm")

Field mapping

The OpenAI Python SDK's audio.speech.create() arguments map cleanly onto ShunyaLabs' POST /v1/audio/speech body:

OpenAI SDK argumentShunyaLabs fieldNotes
modelmodelUse tts-1.
inputinputThe text to synthesize.
voicevoiceA ShunyaLabs voice (for example, Meera). For Pipecat use an OpenAI-compatible voice name such as nova.
response_formatresponse_formatAs supported by the API; raw PCM is useful for streaming and voice-agent pipelines.

What you keep when you switch

  • The OpenAI client's retry / timeout / streaming helpers.
  • Standard response.stream_to_file(), response.iter_bytes() patterns.
  • Same error types your code already catches.
Streaming and voice agents
Request raw PCM output (response_format="pcm") and stream the bytes to your pipeline; this is the recommended path for real-time voice-agent frameworks and Pipecat. See the Pipecat example and the LLM → TTS pipeline.
