LiveKit integration

Run Shunya ASR and TTS inside a LiveKit Agents voice agent. STT uses Shunya's realtime streaming endpoint, TTS uses the OpenAI-compatible endpoint pointed at Shunya.

1. Mint a Bearer token

Exchange your API key for a short-lived Bearer token at POST https://app.shunyalabs.ai/api/auth/token, then pass the token to your clients. Keep the API key on the server side; never send it to end-user clients.

curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'

2. STT with Shunya streaming

Shunya streaming ASR runs over a persistent WebSocket at wss://asrv2prod.shunyalabs.ai/v1/realtime. Audio frames from LiveKit are forwarded to the socket and transcription events arrive as partial and final messages. See ASR streaming for the protocol.

Shunya eventMeaning
partialInterim transcript, emitted continuously as speech is recognised
finalFinal transcript for the segment

3. TTS with the OpenAI-compatible endpoint

For TTS, point a LiveKit OpenAI-compatible TTS client at the Shunya endpoint https://ttsv2.shunyalabs.ai/v1/audio/speech. Pass the Bearer token as the api_key, and select the response format required by your integration as supported by the API. Raw PCM output (response_format="pcm") is useful for streaming and voice-agent pipelines.

Python
from livekit.plugins import openai

tts = openai.TTS(
    base_url="https://ttsv2.shunyalabs.ai/v1",
    api_key="YOUR_TOKEN",
    model="tts-1",
    voice="Meera",
)

4. Full agent example

Python
from livekit.agents import AgentSession, Agent, RoomInputOptions
from livekit.plugins import openai, silero

class MyAgent(Agent):
    def __init__(self):
        super().__init__(instructions="You are a helpful voice assistant.")

async def entrypoint(ctx):
    session = AgentSession(
        stt=stt,          # Shunya streaming STT, see section 2
        tts=openai.TTS(
            base_url="https://ttsv2.shunyalabs.ai/v1",
            api_key="YOUR_TOKEN",
            model="tts-1",
            voice="Meera",
        ),
        vad=silero.VAD.load(),
    )
    await session.start(
        agent=MyAgent(),
        room=ctx.room,
        room_input_options=RoomInputOptions(),
    )
Keep credentials on the server side
Do not expose API keys or auth tokens in browser code, mobile app bundles, public repositories, or logs.
