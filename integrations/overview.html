Docs/Integrations

Platform integrations

SDKs, telephony providers, and platforms that work with Shunya Labs out of the box. Every integration on this page is documented in Shunya's published API guide or SDK reference, pick the one that matches your stack.

Python

Call Shunya TTS from Python. Mint a Bearer token, then requests for the omni-voice endpoint or the OpenAI SDK for the compatible endpoint.

HTTP
OpenAI SDK

The TTS API is OpenAI-compatible. Use the official OpenAI Python SDK, point base_url at Shunya and your existing code keeps working.

Drop-in
SIP / PSTN

Telephony pipelines. ASR streams raw PCM over WebSocket; TTS returns raw PCM (response_format="pcm") on the OpenAI-compatible endpoint.

Telephony
Hugging Face

Open weights at huggingface.co/shunyalabs. Download via huggingface-cli or use the transformers pipeline for local / air-gapped inference.

Self-host
Pipecat

Use Shunya TTS in a Pipecat voice agent with OpenAITTSService, pointed at the Shunya compatible endpoint with the Bearer token as api_key.

Voice agents
LiveKit

Run Shunya ASR and TTS inside LiveKit Agents. STT streams over the Shunya realtime endpoint, TTS uses the OpenAI-compatible endpoint pointed at Shunya.
