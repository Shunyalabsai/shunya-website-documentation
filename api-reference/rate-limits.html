API rate limits

Upload, concurrency, and timeout limits for ASR and TTS requests.

Speech-to-Text (ASR)

LimitValue
Max file size (batch)50 MB
Supported audio formats (batch)wav, mp3, flac, ogg/opus
Streaming audio formatRaw 16-bit signed PCM, little-endian, mono, at 8 kHz or 16 kHz
Access token lifetime~15 minutes (900 s) — cache and reuse, re-mint at /auth/token on expiry
Upload too large413 — exceeds the 50 MB limit
Request timed out504 — didn't complete within the gateway window
Rate limit exceeded429 — retry after the Retry-After window

Text-to-Speech (TTS)

LimitValue
Max text length per request10,000 characters
Recommended per-requestUnder 500 characters for best quality; split longer text
HTTP request timeoutSet to at least 120 s for long text
Concurrent requests (default tier)16
