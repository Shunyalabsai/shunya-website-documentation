Request IDs

Log the request_id from every response — Shunya support uses it to trace issues.

For batch transcription with response_format=verbose_json, the response includes a request_id field. Include it when you contact support; it identifies your request in our logs.

For a streaming session (WS /v1/realtime), there is no session ID in the ready event. Instead, quote the UTC time, language, and approximate call duration when you contact support.
