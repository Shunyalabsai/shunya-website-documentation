API Overview

Cloud APIs for speech-to-text and text-to-speech. Use the sidebar to open General guides or jump straight to an endpoint.

Speech-to-Text (ASR)

Every endpoint under asrv2prod.shunyalabs.ai, their request fields, response shapes, and error codes. All ASR endpoints authenticate with the short-lived access token from POST /auth/token.

Endpoints

Text-to-Speech (TTS)

TTS endpoints under ttsv2.shunyalabs.ai plus the auth endpoint under app.shunyalabs.ai. Authenticate with a short-lived Bearer token minted at POST /api/auth/token. Interactive API documentation is at https://ttsv2.shunyalabs.ai/docs.

AuthPOST https://app.shunyalabs.ai/api/auth/tokenExchange your API key for a short-lived Bearer token.
Standard TTSPOST https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesizeGenerate speech from text.
Education TTSPOST https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize with latex: trueGenerate speech from LaTeX content.
