Integrate via HTTP

No abstractions, just HTTP calls. Mint a short-lived Bearer token from your API key, then call the omni-voice and OpenAI-compatible endpoints directly. Pick this path when you need full control or are working in a language without a client library.

Step 1: Get an API key and mint a Bearer token

Generate an API key from your ShunyaLabs account, then exchange it once for a short-lived Bearer token at POST https://app.shunyalabs.ai/api/auth/token. Send the token as Authorization: Bearer YOUR_TOKEN on every TTS call.

shell
curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'
python
import os, requests

token = requests.post(
    "https://app.shunyalabs.ai/api/auth/token",
    headers={"api-key": os.environ["SHUNYALABS_API_KEY"]},
    json={"expires_in": 86400},
).json()["token"]
  • Store the API key in a backend or secrets manager, never in source code.
  • Mint the token from the backend and reuse it until near expiry, then refresh.
  • Never send the API key to end-user clients.
  • Rotate immediately if a key is compromised.

Step 3: Standard TTS

Send the token as Authorization: Bearer YOUR_TOKEN and post the text plus a voice to /v1/omni-voice/synthesize:

shell
curl -X POST 'https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize' \
  -H "Authorization: Bearer $YOUR_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"text": "Hello, how are you today?", "voice": "Meera"}' \
  --output hello.wav
python
r = requests.post(
    "https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize",
    headers={"Authorization": f"Bearer {token}"},
    json={"text": "Hello, how are you today?", "voice": "Meera"},
    timeout=120,
)
r.raise_for_status()
with open("hello.wav", "wb") as f:
    f.write(r.content)

Step 4: Education TTS (LaTeX)

Use the same endpoint with "latex": true when the input contains LaTeX expressions, and set "language" to identify the content language:

r = requests.post(
    "https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize",
    headers={"Authorization": f"Bearer {token}"},
    json={"text": "If $x^2 = 49$, what is the value of x?", "voice": "Meera", "latex": true, "language": "en"},
    timeout=120,
)

Step 5: OpenAI-compatible endpoint

For voice agents and Pipecat, use POST https://ttsv2.shunyalabs.ai/v1/audio/speech. Raw PCM output (response_format="pcm") is useful for streaming and voice-agent pipelines.

curl -X POST 'https://ttsv2.shunyalabs.ai/v1/audio/speech' \
  -H "Authorization: Bearer $YOUR_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "tts-1",
    "input": "Hello, how are you today?",
    "voice": "Meera",
    "response_format": "pcm"
  }' \
  --output hello.pcm

Step 6: Response formats

Select the response format required by your integration as supported by the API. Raw PCM output (response_format="pcm") is useful for streaming and voice-agent pipelines.

Step 7: Ship checklist

  • ✅ API key stored server side, never source-controlled
  • ✅ Bearer token minted from the backend and reused until near expiry
  • ✅ HTTP client timeout set for long synthesis requests
  • ✅ response_format matched to the use case (PCM for real-time, otherwise as supported by the API)
  • ✅ Credentials kept out of browser code, mobile app bundles, public repositories, and logs
