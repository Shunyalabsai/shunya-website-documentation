For teams already on the OpenAI SDK

Drop in to existing OpenAI code

Already using the OpenAI Python SDK? Keep your code. Point base_url to ShunyaLabs, pass your ShunyaLabs Bearer token as api_key, and call the OpenAI-compatible POST /v1/audio/speech endpoint.

Step 1: Authenticate first

Generate an API key from your ShunyaLabs account, then exchange it for a short-lived Bearer token at the authentication endpoint. Use the token as the api_key in the OpenAI client. Keep the API key on the server side; never send it to end-user clients.

curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'

See Authentication for the full flow.

Step 2: The two-line swap

Take any working OpenAI TTS call. Change base_url and pass your ShunyaLabs token as api_key; use an OpenAI-compatible model and voice name.

Before: vanilla OpenAI

from openai import OpenAI

client = OpenAI(api_key="sk-openai-...")

response = client.audio.speech.create(
    model="tts-1",
    input="Hello, how are you today?",
    voice="alloy",
    response_format="mp3",
)
response.stream_to_file("output.mp3")

After: same SDK, ShunyaLabs backend

from openai import OpenAI

client = OpenAI(
    api_key="YOUR_TOKEN",                 # ShunyaLabs Bearer token
    base_url="https://ttsv2.shunyalabs.ai/v1",
)

response = client.audio.speech.create(
    model="tts-1",
    input="Hello, how are you today?",
    voice="Meera",
    response_format="pcm",
)
response.stream_to_file("output.pcm")

Step 3: What stays the same

  • Client class, OpenAI / AsyncOpenAI from the official openai package.
  • Method shape, client.audio.speech.create(...), same fields.
  • Response shape, response.stream_to_file(), response.read(), response.iter_bytes() all work as in OpenAI.
  • Auth pattern, Bearer token via api_key; the SDK sets the Authorization header for you.

Step 5: Response formats

Select the response format required by your integration as supported by the API. Raw PCM output (response_format="pcm") is useful for streaming and voice-agent pipelines.

Step 6: Async + streaming with the OpenAI SDK

from openai import AsyncOpenAI

client = AsyncOpenAI(
    api_key="YOUR_TOKEN",
    base_url="https://ttsv2.shunyalabs.ai/v1",
)

async with client.audio.speech.with_streaming_response.create(
    model="tts-1",
    input="Hello, how are you today?",
    voice="Meera",
    response_format="pcm",
) as response:
    async for chunk in response.iter_bytes():
        play(chunk)   # PCM bytes arrive as they are generated

Step 7: Pipeline: GPT-4 → ShunyaLabs TTS

Use one OpenAI client for the LLM, a second OpenAI client (pointed at ShunyaLabs) for TTS. Stream tokens, flush at sentence boundaries:

from openai import AsyncOpenAI

oai     = AsyncOpenAI()                                      # default OpenAI base_url
shunya  = AsyncOpenAI(base_url="https://ttsv2.shunyalabs.ai/v1",
                      api_key="YOUR_TOKEN")

buffer = ""
stream = await oai.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True,
)
async for chunk in stream:
    token = chunk.choices[0].delta.content or ""
    buffer += token
    if token in (".", "!", "?", ";") and len(buffer) > 15:
        async with shunya.audio.speech.with_streaming_response.create(
            model="tts-1", input=buffer, voice="Meera", response_format="pcm",
        ) as resp:
            async for audio in resp.iter_bytes():
                play(audio)
        buffer = ""

Step 8: Why teams choose this path

Zero migration cost

If your codebase already uses the OpenAI SDK, the swap is a few lines. No new dependencies, no rewrites, no team retraining.

Voice-agent ready

The endpoint is designed for real-time voice-agent frameworks and Pipecat-style integrations, with raw PCM output for streaming pipelines.

Multi-vendor without multi-codebase

Keep OpenAI for other paths and route TTS traffic to ShunyaLabs, both via the same client class.

Pipecat support

Configure OpenAITTSService with base_url="https://ttsv2.shunyalabs.ai/v1" and your Bearer token; see the Pipecat example.
