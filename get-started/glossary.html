Term glossary

Plain-English definitions for terms in these docs. STT = speech-to-text (audio → text). TTS = text-to-speech (text → audio).

Speech-to-Text (STT)

Audio in, text out. Shunya product family: Zero STT. Also called ASR (automatic speech recognition).

STT (speech-to-text)
Converting spoken audio into written text. Shunya endpoint: POST /v1/audio/transcriptions.
ASR (automatic speech recognition)
Another name for STT, same meaning.
Batch STT
Upload a complete audio file; receive the full transcript when done.
Streaming STT
Send live audio over WebSocket; receive partial transcripts while the person is still speaking.
Transcript
The text returned by STT, plain text or JSON with segments and timestamps.
Translation
Converting text from one language to another. Often used after STT. Shunya product: Vāķ.
Sample rate
Audio samples per second. 16 kHz for recordings; 8 kHz for phone lines.
PCM
Raw uncompressed audio, common for low-latency streaming STT.
μ-law / A-law (G.711)
8 kHz phone codecs common on PSTN and SIP lines. Streaming ASR expects raw 16-bit signed PCM, mono, at 8 kHz or 16 kHz, so convert G.711 audio to that format before sending.
VAD (voice activity detection)
Detects when someone is speaking vs silent.
Diarization
Labels who spoke when. Set diarize (plus num_speakers); the verbose response includes speakers, speaker_turns, and a speaker on each segment.
Speaker enrolment
Register a known speaker's voice with a name via POST /v1/speakers/register (and remove with DELETE /v1/speakers/delete).
Code-switching
Mixing languages in one utterance (e.g. Hinglish). Model: zero-codeswitch.
Transliteration
Same words in a different script. Not a parameter of the STT API; translation across scripts is handled by Vāķ Translate.
Word timestamps
Start and end time for each word in the transcript. Returned with response_format=verbose_json.
WER (word error rate)
STT accuracy metric, lower is better. Shunya does not publish benchmark WER figures in the API reference.
Intent detection
Classifies what the speaker wanted from the transcript.
Sentiment analysis
Whether speech sounds positive, negative, or neutral.
NER (named entity recognition)
Extracts names, dates, amounts, and places from a transcript.
Keyterm normalization
Standardizes domain terms in the transcript.
Profanity hashing
Masks offensive or sensitive words in STT output.

Text-to-Speech (TTS)

Text in, audio out. Shunya product family: Zero TTS. The new endpoints below are the recommended integration path for new client implementations.

TTS (text-to-speech)
Converting written text into spoken audio. Shunya endpoints: POST /v1/omni-voice/synthesize (standard and education) and POST /v1/audio/speech (OpenAI-compatible).
Auth token (Bearer token)
Short-lived token minted from your API key at POST https://app.shunyalabs.ai/api/auth/token using the api-key header and an expires_in body (seconds). Send it as Authorization: Bearer on every TTS call.
Standard TTS
Synthesize speech from plain text with POST /v1/omni-voice/synthesize. Key fields: text (content to synthesize) and voice (requested ShunyaLabs voice).
Education TTS (LaTeX)
Same omni-voice/synthesize endpoint with "latex": true when the input contains LaTeX expressions, and language identifying the content language.
OpenAI-compatible TTS
POST /v1/audio/speech with the OpenAI request shape (model, input, voice, response_format). Select the response format as required by your integration, as supported by the API.
Raw PCM
Raw audio output from the OpenAI-compatible endpoint, useful for streaming and voice-agent pipelines.
Voice
Which speaker reads the text. Voice and language support is confirmed per client plan.
Pipecat
A voice-agent framework. Shunya TTS plugs in as OpenAITTSService pointed at https://ttsv2.shunyalabs.ai/v1.
Prosody
Rhythm and intonation of spoken output.

Deployment & security

Sovereign AI
AI where data and models stay under your organization's control and jurisdiction.
Air-gapped
Deployment with no connection to the public internet.
CPU-compatible / CPU-first
Models that run on standard CPUs without a GPU.
SOC 2 Type II
Third-party audit of security controls over time.
ISO 27001:2022
International information security management standard.
HIPAA
US healthcare privacy law, requires a BAA for PHI.

Infrastructure

Triton Inference Server
NVIDIA inference server used to serve models at scale.
WebSocket
Persistent connection used for streaming STT (ASR realtime transcription).
Bearer token
Short-lived token minted from your API key and sent as Authorization: Bearer <token>. ASR mints an access token at POST /auth/token; TTS mints a Bearer token at POST https://app.shunyalabs.ai/api/auth/token.
