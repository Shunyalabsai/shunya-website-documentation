Your quickstart

Get from nothing to a working transcription and a working synthesis in five minutes. You'll need an API key and about three lines of code per direction.

1. Get an API key

  1. Sign in at accounts.shunyalabs.ai.
  2. Navigate to API Keys and click Create New Key.
  3. Copy the key immediately, it's shown once.
Keep the key out of source control
Store it in a .env file or a secrets manager. Add .env to .gitignore. Rotate if leaked.

Set the environment variable

export SHUNYALABS_API_KEY="sk-your-key-here"
$env:SHUNYALABS_API_KEY = "sk-your-key-here"

2. Transcribe an audio file

ASR authenticates with a short-lived access token: exchange your API key once at POST /auth/token, then send the token on every request. Never send your API key to the transcription endpoints.

shell
# 1. Mint an access token (POST /auth/token)
curl --request POST 'https://asrv2prod.shunyalabs.ai/auth/token' \
  --header 'accept: application/json' \
  --header "Authorization: Bearer $SHUNYALABS_API_KEY"
# → { "token": "<access_token>", "expires_at": ..., "expires_in": 900 }

# 2. Transcribe with the token
export ACCESS_TOKEN="<access_token>"
curl -X POST https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -F "file=@meeting.wav" \
  -F "model=zero-indic"
python
import os, requests

# 1. Mint an access token (POST /auth/token)
token = requests.post(
    "https://asrv2prod.shunyalabs.ai/auth/token",
    headers={"Authorization": f"Bearer {os.environ['SHUNYALABS_API_KEY']}"},
).json()["token"]

# 2. Transcribe with the token
with open("meeting.wav", "rb") as f:
    r = requests.post(
        "https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions",
        headers={"Authorization": f"Bearer {token}"},
        files={"file": f},
        data={"model": "zero-indic"},
    )
r.raise_for_status()
print(r.json()["text"])
node
import fs from "node:fs";

// 1. Mint an access token (POST /auth/token)
const tokenResp = await fetch("https://asrv2prod.shunyalabs.ai/auth/token", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.SHUNYALABS_API_KEY}` },
});
const { token } = await tokenResp.json();

// 2. Transcribe with the token
const form = new FormData();
form.append("file", new Blob([fs.readFileSync("meeting.wav")]), "meeting.wav");
form.append("model", "zero-indic");

const r = await fetch("https://asrv2prod.shunyalabs.ai/v1/audio/transcriptions", {
  method: "POST",
  headers: { Authorization: `Bearer ${token}` },
  body: form,
});
const data = await r.json();
console.log(data.text);
openai SDK
import os, requests
from openai import OpenAI

# 1. Mint an access token (POST /auth/token)
token = requests.post(
    "https://asrv2prod.shunyalabs.ai/auth/token",
    headers={"Authorization": f"Bearer {os.environ['SHUNYALABS_API_KEY']}"},
).json()["token"]

# 2. Transcribe with the token
client = OpenAI(
    api_key=token,
    base_url="https://asrv2prod.shunyalabs.ai/v1",
)
r = client.audio.transcriptions.create(
    model="zero-indic",
    file=open("meeting.wav", "rb"),
)
print(r.text)

Response

Default response_format=json returns just the transcript; use response_format=verbose_json for segments, words, and timing:

{
  "text": "नमस्ते मोहम्मद जी, ये एक ज़रूरी कॉल है।",
  "audio_duration": 5.7,
  "inference_time_ms": 812.3,
  "request_id": "c1a686efeedf",
  "success": true,
  "segments": [ { "start": 0.51, "end": 5.70, "text": "नमस्ते मोहम्मद जी..." } ]
}

3. Generate speech

TTS authenticates with a Bearer token: exchange your API key once at POST https://app.shunyalabs.ai/api/auth/token, then call the Omni Voice synthesis endpoint. The response body is audio bytes.

shell
# 1. Mint a Bearer token (POST /api/auth/token)
curl -X POST 'https://app.shunyalabs.ai/api/auth/token' \
  -H 'api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"expires_in": 86400}'
# → { "token": "<your_token>", ... }

# 2. Synthesize with the token
export YOUR_TOKEN="<your_token>"
curl -X POST 'https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize' \
  -H "Authorization: Bearer $YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello, how are you today?","voice":"Meera"}' \
  --output hello.wav
python
import os, requests

# 1. Mint a Bearer token (POST /api/auth/token)
token = requests.post(
    "https://app.shunyalabs.ai/api/auth/token",
    headers={"api-key": os.environ["SHUNYALABS_API_KEY"]},
    json={"expires_in": 86400},
).json()["token"]

# 2. Synthesize with the token
r = requests.post(
    "https://ttsv2.shunyalabs.ai/v1/omni-voice/synthesize",
    headers={"Authorization": f"Bearer {token}"},
    json={"text": "Hello, how are you today?", "voice": "Meera"},
    timeout=120,
)
r.raise_for_status()
with open("hello.wav", "wb") as f:
    f.write(r.content)
openai SDK
import os, requests
from openai import OpenAI

# 1. Mint a Bearer token (POST /api/auth/token)
token = requests.post(
    "https://app.shunyalabs.ai/api/auth/token",
    headers={"api-key": os.environ["SHUNYALABS_API_KEY"]},
    json={"expires_in": 86400},
).json()["token"]

# 2. Synthesize with the token
client = OpenAI(api_key=token, base_url="https://ttsv2.shunyalabs.ai/v1")
resp = client.audio.speech.create(
    model="tts-1",
    input="Hello, how are you today?",
    voice="Meera",
    response_format="pcm",
)
resp.stream_to_file("hello.pcm")

4. Stream for voice agents

ASR streams live audio over WebSocket, see ASR streaming. On the TTS side, the OpenAI-compatible POST /v1/audio/speech endpoint returns raw PCM audio, which is useful for streaming and voice-agent pipelines. See the LLM → TTS pipeline for the sentence-by-sentence pattern.
